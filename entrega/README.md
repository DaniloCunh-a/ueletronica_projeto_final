# Pacote de Entrega Final

Esta pasta consolida os artefatos finais do desafio de design de CI.

## Estrutura
- `schematic/`: esquemáticos finais e símbolos.
- `sim_pre/`: testbench pre-layout, logs e figuras.
- `layout/`: `.mag`, `.gds` e screenshots de layout.
- `pex_post/`: netlist extraída, testbench pós-layout, logs e figuras.
- `verification/`: relatórios DRC/LVS e evidências de execução.
- `report/`: paper final (PDF), figuras e tabelas de comparação.

## Regra prática
Cada subpasta deve conter:
1. arquivos fonte;
2. evidência visual (PNG/PDF) quando aplicável;
3. um `README.md` curto com comando usado para gerar os arquivos.
